# 2026-07-31 工作日志

## ocrflow 项目开发

### 任务
基于 https://github.com/zibo-chen/rust-paddle-ocr 开发全平台 OCR 识别软件，支持批量上传、批量识别、AI 优化。

### 完成内容
1. **创建新项目** `/home/nana/Projects/personal/ocrflow`，独立于 hyshot
2. **后端核心** (Rust):
   - `src/ocr.rs` — ocr-rs 引擎封装，Rayon 并行批量识别
   - `src/ai.rs` — OpenAI 兼容 API 调用，LLM 修正 OCR 错误
   - `src/server.rs` — Axum HTTP 服务器，multipart 批量上传
   - `src/main.rs` — CLI + Web 双模式入口
3. **前端 UI** — 单页 HTML/CSS/JS，暗色主题，拖拽上传、结果展示、AI 优化
4. **模型下载脚本** `scripts/download_models.sh` — 支持 v6 small/medium + v5 mobile 下载
5. **编译测试** — release 构建成功，二进制 13MB，OCR 测试中英文识别准确率 >99%

### 技术要点
- ocr-rs crate (v2.3.x) 模型直接存储在 GitHub 仓库 models/ 目录，非 release assets
- **PP-OCRv6 模型在 `next` 分支**（main 分支只有 v4 和 v5）
- v6 small 模型: det 4.8MB + rec 10.1MB + keys 75KB
- ocr-rs 的 OcrEngine::new 接受 &str 路径参数
- Axum multipart 上传 + spawn_blocking + rayon 并行处理批量图片
